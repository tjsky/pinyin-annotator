## 為什麼做這個

替低年級孩子產生帶漢語拼音注音的讀物時，網路上的工具不是彈廣告、就是把文章上傳到伺服器，再不然就是多音字錯得離譜還不能改。這個小工具就是為了解決這些痛點：

- **內容不出本機**：所有注音轉換都在瀏覽器裡完成，處理校內稿件、孩子姓名都沒有隱私顧慮；
- **準確率第一梯隊**：基於 [pinyin-pro](https://github.com/zh-lx/pinyin-pro)（官方基準準確率 99.846%），詞組級多音字消歧（銀行 / 行走 / 睡著了）；
- **錯了能改**：點任意生字手動改讀音，輕聲（子 zi、地 de、著 zhe）、兒化音都能強制指定。

## 功能特色

### 音標與讀音

**九種音標方案**：側欄「音標方案」一鍵切換。讀音一律以拼音儲存，切方案只換寫法——手動改過的讀音、台灣讀音標準照常生效，預覽、列印與五種複製格式同步。

| 方案 | 寫法特點 | 例：春天來了 |
| --- | --- | --- |
| 漢語拼音 | 教材與《漢語拼音方案》的寫法，調號標在主要元音上 | chūn tiān lái le |
| 注音符號（ㄅㄆㄇ） | 台灣注音符號，可橫排或直排（標在字右側） | ㄔㄨㄣ ㄊㄧㄢ ㄌㄞˊ ˙ㄌㄜ |
| 通用拼音 | zh→jh、j/q/x→j/c/s、舌尖元音 -ih、ㄩ 系作 yu、-iou / -uei 不縮寫；一聲與輕聲不標調 | chun tian lái le |
| 耶魯拼音（國語耶魯） | zh/ch/sh→j/ch/sh、z/c/s→dz/ts/s、x 作 sy、-un 作 -wun、-ui 作 -wei；七個空韻用空格調號 | chwūn tyān lái le· |
| 威妥瑪（嚴式） | 老派英文漢學寫法：保留送氣符 ʻ、ü 與上標調號 | chʻun¹ tʻien¹ lai² le⁵ |
| 威妥瑪（簡式） | 同上但省略送氣符；可切「數字 / 不標」與「ü / u」 | chun¹ tien¹ lai² le⁵ |
| 注音二式（MPS2） | ㄐ/ㄑ/ㄒ 與翹舌同作 j/ch/sh，空韻翹舌後作 r、舌齒後作 z，ü 作 iu、ao 作 au | chuēn tiān lái le |
| 國語羅馬字（GR） | **不用調號，靠拼寫區分四聲**：一聲基式、二聲加 r 或換 y/w、三聲雙寫或換 e/o、四聲改韻尾或綴 h；輕聲綴「.」 | chuen tian lai .le |
| 西里爾轉寫（Палладиус） | 俄語圈沿用至今的標準；上標數字調 ¹—⁵，可關掉；預覽與列印自動切系統西文字型堆疊 | чунь¹ тянь¹ лай² лэ⁵ |

威妥瑪簡式與西里爾轉寫的「聲調」可關；拉丁字母方案可把音標放到字的右側（「拼音位置」），注音可橫排 / 直排（「注音方向」）。

- **教材式上下注音排版，輕聲自動不標調**（媽媽 mā ma）。
- **一/不變調**：標變調（一個 yí gè，語流中的實際讀音）或標本調（一個 yī gè，詞典裡的聲調），依教材習慣選擇。
- **兒化音雙模式**：**分開標**（花兒 huā er，適合指讀認字）/ **合併標**（花兒 huār，符合漢語拼音方案），女兒、兒童等真音節詞自動修正。
- **單字手動改讀音**：點生字彈出候選（含輕聲 / 助詞讀音），改過的字標橘色。
- **按詞連排**（主線版 / 完整詞典版）：內建約 3 萬現代漢語常用詞詞典，「連排方式」可選「按詞連排」（詞組的字連在一起注音、詞間留空隙，更貼近教材詞組排版；多字詞讀音按詞典標註更準，如 長長 cháng cháng、銀行 yín háng）、「從後匹配」與「逐字注音」（預設）；也可點擊任意生字在彈窗中手動斷詞 / 合詞，修正機器分詞錯誤。
- **儲存設定 / 回復預設**：調好的排版存為下次開啟的預設值；改亂了點「回復預設」一鍵還原。
- **單字兒化修正**：人名「潤兒」誤判成兒化？點「兒」字一鍵強制兒化 / 非兒化。
- **易錯字標色**：用底色標出多音字、兒化音、的 / 地 / 得、一 / 不 變調、常見輕聲字，掃一眼就知道該核對哪裡。
- **內建常用輕聲詞典**：豆子、椅子、高興地、慢慢地等直接標對
- **拼音引擎內嵌離線可用**，同時支援連網同步上游更新（jsDelivr / npmmirror 雙來源）

### 排版與輸出

- 漢字 16–48px 字級；漢字字型可選楷體 / 宋體 / 黑體，或霞鶩文楷 GB / 霞鶩文楷 TC / 芫荽 Iansui（線上字型，按需載入並自動快取）；音標字型獨立設定，也可選本機已安裝的字型。
- **簡⇄繁轉換引擎**：由 OpenCC 驅動，「更多設定 → 繁簡轉換」可選 **簡體 ⇆ 標準繁體 / 台灣繁體 / 香港繁體**；勾選「同時轉換常用詞彙」後可以連地區用詞一併轉換（滑鼠、軟體、列印這類台灣說法），一字多繁（同一個簡體字對應不同繁體，如 頭髮 / 發財）也始終自動區分。
- **內嵌拼音 / 注音專用字型**：楷體、宋體等常見中文字型裡的拼音是普通拉丁字母寫法（雙層 a），不是教材拼音。工具內嵌 Andika 拼音字型（預設，顯示教材單層 ɑ / 單層 g）與 ㄅㄆㄇ 注音字型 BpmfSubset（注音模式自動選用，也可在「音標字型」手動指定），**無需額外安裝任何字型**；以上均以 SIL OFL 1.1 協議開源，**可免費商用**。
- **可選「印氪先生拼音字型」**：一款更接近教材上拼音效果的字型，在偵測到本機已安裝時會**自動切換**；未安裝而手動選擇時會提示下載並給出安裝步驟（下載 → 解壓 → 雙擊 ttf → 點「安裝」→ **重新啟動瀏覽器**後點「重新偵測」）。安裝後即可預設呼叫，注意該字型**僅限非商業場景使用**，專案程式碼不包含字型檔案，詳見下方「字型版權說明」。
- **列出本機所有字型**：預設只列常用字型，避免下拉清單過長；勾選後瀏覽器會請求「字型存取」權限，本機字型依名稱去重排序，以「本機已安裝字型」分組附加到漢字字型與音標字型兩個下拉框，取消勾選即回復。該功能只有電腦版 Chrome / Edge 支援，手機 / 平板用內建字型即可。
- **A4 紙樣式預覽**：依 A4 紙寬高自動分頁（每頁容納字數隨字級、間距自動變化），所見即所印；手機等窄螢幕自動改為適應螢幕寬度的連續排版。
- **長文模式（整本書支援）**：貼上或匯入超過 3 萬字時自動進入（上限 200 萬字），全文切成約 3 萬字的區塊逐塊排版，邊處理邊可翻閱（進度條即時顯示）；預覽只渲染目前頁，翻頁時再按需排版，不卡瀏覽器介面。輸入框轉為唯讀摘要狀態，點「退出長文模式」回復編輯。
- **字間距 / 行間距 / 段間距滑桿即時調節**，解決長拼音黏連問題。
- **三檔對齊**：預設「左對齊」；「置中」所有內容都置中（律詩、絕句、歌詞）；「詩詞」依最長的一行置中後，其他文字再與它左對齊（詞、賦、現代詩）。詩詞模式下點預覽左側的行號（手機長按某一行），可以單獨調整這一行。
- **翻頁 / 連續捲動**兩種預覽方式：翻頁依 A4 逐頁顯示（翻頁按鈕或鍵盤 ←→），連續捲動一屏到底。
- **列印 / PDF**：A4 教材排版輸出全部頁面，頁尾浮水印可勾選移除。長文模式下改為彈出列印對話框：可按**頁碼範圍**列印，或**分批列印全書**（每批 100 頁，上一批儲存後自動彈出下一批），再用對話框裡的「合併 PDF 檔案」把各批依檔名順序合成一個 PDF（使用 pdf-lib 在你的瀏覽器內合併，全程本機不上傳；僅合併工具本身首次使用時需連網載入）。
- **五種複製格式**：貼到 Word（保留注音排版）、網頁 ruby 標籤、網頁注音（HTML+CSS，網頁原始碼，引用隨站點部署的 `zhuyin.css`，橫排 / 直排都與預覽一致，可選配 font.emtech.cc 線上字型如芫荽 Iansui / 霞鶩文楷 TC）、字-音標 對照、只複製音標（保留原文標點與分段，適合出練習題）；音標隨目前模式——拼音模式複製拼音，注音模式複製注音（ㄅㄆㄇ）。Word 對注音聲調定位支援有限（要在 Word 裡精確注音，得逐一適配多種注音字型，超出了這麼一個幾 MB 線上工具的能力），所以「貼到 Word」出來的注音是橫排、聲調符號綴在音節末尾。
- **注音芫荽 IVS 模式**：「網頁注音（HTML+CSS）」直排 + 網頁字型選「注音芫荽 BpmfIansui」時，每個字的正確讀音以 IVS 異體字選擇符（U+E01E0+序號，規格見 ButTaiwan/bpmfvs）寫入文字，由字型自行標註右側注音；多音字讀音隨本工具的台灣讀音資料選取，讀音表（18,626 字，建置期從 bpmfvs 讀音表 `phonic_table_Z.txt` 產生，僅注入注音版）未收的字自動切回常規字形並用結構標註，不會顯示字型預設的錯誤讀音。橫排時該字型僅用於注音符號（其漢字字形自帶注音，整段套用會重複標註）；裝有注音芫荽字型的 Word 等軟體可直接使用帶 IVS 的文字，輸出真實正確的注音。
- **閱讀模式**：隱藏編輯區，裝置直接遞給小朋友，方向鍵翻頁；底部還有一條跟讀工具列：逐句高亮、自動捲動 / 翻頁，可以用瀏覽器語音朗讀課文，也能開麥克風讓孩子跟著讀（實驗功能），點課文裡的字直接跳到那一句；關掉時記住讀到哪，下次進來接著讀。

### 匯入

- TXT 檔案匯入，自動辨識 UTF-8 / GBK 編碼；單一檔案上限 2 MB。

## 快速開始

- **線上使用：**[拼音注音小助手（海外使用者推薦）](https://tjsky.github.io/pinyin-annotator/) | [拼音注音小助手（中國大陸使用者推薦）](https://pinyin-annotator.tjsky.net/)

  首次造訪會展示四個版本的對比卡片，選一個進入即可；選過之後瀏覽器會記住，下次自動進入上次用的版本（也可在頁面換版本）；
- **本機使用**：
  1. 前往 [Releases](https://github.com/tjsky/pinyin-annotator/releases) 下載最新版（Assets 裡的 `pinyin-annotator-vX.Y.Z.zip`）；
  2. 解壓後雙擊 `index.html`（版本選擇頁）——完成，不需要安裝任何東西；首次造訪會展示四個版本的對比卡片，選一個進入即可，瀏覽器會記住選擇、下次自動進入（也可在頁面換版本；本機開啟舊入口 `main.html` 會提示改用 `pinyin.html`）；
  3. 貼上文章 → 選音標、調字級與間距 → 勾「易錯字」過一遍 → 列印 / 匯出 PDF，或複製進 Word；也可以點「閱讀模式」直接遞給孩子讀。

| 版本          | 檔案            | 體積       | 與其他版本的差別                                                        |
| ----------- | ------------- | -------- | --------------------------------------------------------------- |
| **版本選擇頁**   | `index.html`  | 約 20 KB  | 簡 / 繁 / 英文三語、四版本對比、記住上次選擇、完整詞典版下載進度                             |
| **輕量版**     | `mini.html`   | 約 1 MB   | 沒有詞組詞典，只能逐字注音；**其餘功能與其他版本一致**                                   |
| **主線版**（推薦） | `pinyin.html` | 約 1.4 MB | 內建 3 萬常用詞，可按詞連排；線上示範預設進入這個版本                                    |
| **完整詞典版**   | `plus.html`   | 約 7.2 MB | 詞典擴到 33.7 萬詞（成語、人名地名也能整詞排）+ OpenCC 簡 ⇄ 繁                          |
| **注音版**     | `zhuyin.html` | 約 2.3 MB | 預設繁體介面 + 注音符號 + 台灣讀音 + OpenCC 簡 ⇄ 繁 + 注音芫荽 IVS 讀音表              |

四個版本的介面、排版、列印、閱讀模式完全一致，只差詞典大小與簡繁轉換。

全部版本均支援 **簡體 / 繁體 / English 介面**、**九種音標方案**（漢語拼音 / 注音符號 / 通用拼音 / 耶魯拼音 / 威妥瑪嚴式、簡式 / 注音二式 / 國語羅馬字 / 西里爾轉寫），以及 **一/不變調**（標變調 / 標本調）。拉丁字母方案均可切「拼音位置」（**上方**預設 / **右側**）；注音模式提供「注音方向」切換：**橫排**（符號橫寫標在字上方，調號標在末符上方）與**直排**（台灣直式教科書風格，符號自上而下豎排、標註在漢字右側，調號標在末符右方）；切換後 A4 預覽自動重新分頁，列印 / 匯出 PDF 所見即所印。

「更多設定 → 讀音標準」可切換 **普通話讀音 / 台灣讀音**（拼音與注音模式都生效）：普通話讀音以《現代漢語詞典》為準（資料來源 [zh-lx/pinyin-pro](https://github.com/zh-lx/pinyin-pro)）；台灣讀音以《重編國語辭典修訂本》為準（資料來源 [g0v 萌典](https://github.com/g0v/moedict-data)），涵蓋約 1.5 萬詞、200 字（簡繁字形均可命中，如垃圾 ㄌㄜˋㄙㄜˋ、期待 ㄑ丨ˊ、攜帶 ㄒ丨、血液 ㄒ丨ㄝˇ、混淆 ㄏㄨㄣˋ丨ㄠˊ），詞典文本授權為 CC BY-ND 3.0 臺灣（授權條款要求保留的原始署名：教育部）。

`zhuyin.html` 與 `plus.html` 內嵌 [OpenCC（nk2028/opencc-js）](https://github.com/nk2028/opencc-js)（Apache-2.0），輸入區提供「轉為簡體 / 轉為繁體」一鍵轉換；「更多設定 → 繁簡轉換」可選 **簡體 ⇆ 標準繁體 / 台灣繁體 / 香港繁體**，配合「同時轉換常用詞彙」勾選（台灣 / 香港繁體時可用）連地區用詞一併轉換；`zhuyin.html` 首次開啟即為繁體介面、注音符號與台灣讀音（可隨時切換）。

> 建議使用 Chrome / Edge 等現代瀏覽器，手機 / 平板同樣可用：介面會自動改成上下排列，翻頁變為連續滑動；手機上裝不了本機字型，用內建的 Andika 拼音字型即可，閱讀模式的朗讀與跟讀照常可用。全部功能在本機執行、文章永不上傳；連網僅用於可選的拼音引擎更新檢查與線上字型載入（不選線上字型即完全離線）。
>
> 自行部署到靜態託管（GitHub Pages / Cloudflare Pages / Vercel 等）時，使用 **`dist` 分支**的內容（或 Releases zip 解壓）放到根目錄即可，入口即版本選擇頁；文章裡分享指定版本可用 `https://你的網域/?v=plus` 這樣的參數直接存取對應版本（`?v=pinyin` / `?v=zhuyin` / `?v=mini` 同理，舊連結 `?v=main` 自動相容跳轉主線版）。詳見下方「部署線上版」。

## 部署線上版（GitHub Pages / Cloudflare Pages / Vercel）

本倉庫採用**原始碼與成品分離**的架構：

| 分支 / 位置 | 內容 | 用途 |
| --- | --- | --- |
| `main` | 原始碼：`template.html` + `build.js` + 建置依賴（fonts / vendor / seg-dict） | 開發與 PR，**不含工具成品** |
| `dist` | CI 自動建置的工具成品：`index.html` + `main.html` + `zhuyin.css` + 四個版本頁 + `.nojekyll` | **三平台線上託管的生產分支**，由 CI 自動建置覆蓋 |
| Releases | 每個版本 tag 的成品 zip | 本機使用下載 |

### Fork 後自架部署（三平台任選）

1. **Fork 本倉庫**，確認 Fork 的 **Actions 已啟用**（Fork 倉庫頁 Actions 標籤頁 → 如提示已停用則點啟用）；Fork 預設只有 main 分支——手動觸發一次工作流即可產生 dist：Actions → Build & Deploy → Run workflow，或隨便改點程式碼發一個新提交；
2. 依所用平台選擇：
   - **GitHub Pages**：Settings → Pages → Build and deployment → Source 選 **Deploy from a branch** → Branch 選 **`dist`**，目錄 **/ (root)** → Save；
   - **Cloudflare Pages**：連接 Fork 倉庫，**Production branch 填 `dist`**，Build command 留空、輸出目錄填 `/`；
   - **Vercel**：匯入倉庫後，Settings → Git → **Production Branch 改為 `dist`**（無需建置指令）；
3. 等 1–2 分鐘建置完成，用分配的網域或自訂網域存取即可。

> 往後更新只需同步上游 `main`（Fork 頁面 Sync fork），CI 會自動重建 `dist`，三平台自動跟隨發佈，全程無需手動下載或上傳任何檔案。任一線上頁面執行 `curl -s <頁面網址> | grep -o "build:v[0-9.]*"` 可核對部署的建置版本號。

## 本機建置

環境要求：**Node.js ≥ 18**（推薦 22，與自動化建置使用的版本一致），零 npm 依賴，複製後直接建置：

```bash
git clone https://github.com/tjsky/pinyin-annotator.git
cd pinyin-annotator
node build.js
```

建置會在倉庫根目錄產生 `mini.html` / `pinyin.html` / `plus.html` / `zhuyin.html` 四個單檔成品（`index.html`、`main.html`、`zhuyin.css` 為手工維護的原始檔，不參與建置）。

- **建置版本號**：`build.js` 內 `BUILD_VERSION` 常數隨發版遞增，注入為每個成品 head 內的隱藏註解 `<!--build:x.y.z-->`，用於線上部署核對；
- **可重現性**：相同 Node 版本下成品應逐位元組一致；換系統或換 Node 版本時，zlib 壓縮結果可能不同，成品雜湊會與倉庫裡的不一致（詞典解壓後完全一致，功能沒有差異）。CI 固定使用 Node 22.22.2；
- **詞典再產生**：`seg-dict/` 內包含 `build-complete.js`、`build-tw-diff.js`、`gen-bpmf-ivs.py`，僅在需要更新上游詞典 / 萌典差異 / 注音讀音表資料時使用，日常建置無需執行。
- **多音補表自檢**：`template.html` 裡的 `POLY_EXTRA` 收錄引擎缺失的讀音（如 騎 jì、偕 jiē）。升級引擎後執行 `node check-poly-extra.js`，會列出「上游已收錄（可刪除）」「上游仍缺失」兩類條目，避免與引擎重複或衝突。
- **音標轉寫對照**：`node check-translit.js` 用 kfcd/pinyin 的 2095 條音節逐條核對通用拼音、耶魯拼音、威妥瑪（嚴式 / 簡式）、注音二式、國語羅馬字、西里爾轉寫的拼寫與調值（國語羅馬字拼寫即承載聲調；國語羅馬字與西里爾都直接逐字元比對）；簡式的兩個開關也會自檢。漢語拼音與注音符號是基準寫法，不參與比對。先在倉庫根目錄放一份對照表：`gh api repos/kfcd/pinyin/contents/pinyinbiao -H "Accept: application/vnd.github.raw" > .ty-biao.tsv`（該檔案不入庫）。
- **候選讀音自檢**：`node check-alts.js` 掃描全部多音字，檢查九種方案下的候選是否混入方案外的字元（如注音模式裡出現拉丁字母）或顯示重複的選項。
- **內嵌字型**：`fonts/build-andika.py <Andika-Regular.ttf>` 重建 Andika 子集，`fonts/check-coverage.py` 檢查兩個內嵌字型是否涵蓋所有音標方案用到的字元（含組合調號與 unicode-range）。兩者需要 `pip install fonttools brotli`，僅改字型時使用。
- **訪問統計（可選，僅官方部署）**：統計程式碼不寫在原始碼裡，由 `inject-analytics.js` 在 CI 推送 `dist` 前注入，因此**本機構建的成品與 Release 包都是乾淨的**。想給自己的部署接統計，設好 `UMAMI_WEBSITE_ID`、`UMAMI_HOST`（`UMAMI_SCRIPT_NAME` 視實例設定可選）再執行 `node inject-analytics.js dist`；未設 ID 時腳本直接跳過，不會失敗。

## 參與貢獻

歡迎 Issue 與 PR！提交前請先看 [已知問題](#已知問題) 與 [開發計畫](#開發計畫待修正問題)，避免重複勞動。

**提交流程（重要：只改原始碼，不要手改成品）：**

1. Fork 倉庫，從 `main` 拉出功能分支；
2. **所有功能改動都在 `template.html`（唯一原始檔）裡做**；改建置腳本與詞典資料則分別改 `build.js` 與 `seg-dict/`。main 分支沒有四個工具頁——它們由自動化建置腳本產生，**請不要在 PR 裡出現任何成品檔案的改動**；
3. 本機 `node build.js` 自測通過後提交，發起 PR；
4. CI 會自動建置，成品掛在 workflow run 的 **Artifacts** 上，可直接下載驗證效果；
5. 審查合併後，`dist` 分支與線上頁面自動更新，無需任何手工發佈步驟。

## 隱私與安全說明

- 所有注音轉換在瀏覽器本機完成，**文章內容不上傳到任何伺服器**；
- 「檢查拼音引擎更新」僅向 jsDelivr / npmmirror 請求引擎版本號與程式碼，不涉及文章內容；
- 線上字型（霞鶩文楷 GB / TC、芫荽等）僅在主動選擇時從 CDN 載入字型檔案，不涉及文章內容；
- 長文模式「合併 PDF」所用的合併元件（pdf-lib）首次使用時從 CDN 載入，之後走瀏覽器快取，合併過程完全在本機完成；
- 閱讀模式的「朗讀」用瀏覽器內建語音，念的就是頁面上這篇文章，不經過任何伺服器；「麥克風跟讀」走瀏覽器的語音辨識，瀏覽器廠商可能會處理音訊（首次開啟前會先詢問一次），介意的話不開就行；
- 工具不收集任何個人資訊，無廣告。**官方線上版**用自架的 Umami 做匿名訪問統計（無 Cookie、不收集文章內容、不記錄可辨識個人的資訊），只為知道有多少人在用；**從 Release 下載的離線檔案、以及 fork 後自建部署的版本都不含統計程式碼**。

## 準確性說明

拼音引擎準確率約 99.8%，但**不承諾 100% 正確**——多音字、輕聲、兒化音在特定語境（尤其是人名、專名）下仍可能誤判。各版本內嵌詞典不同、多音字處理能力也不同（完整詞典版最高，預覽框底部有相應提示）。工具因此提供：

- 易錯字標色，掃一眼就知道哪裡該核對（教學場景建議逐字過一遍）；
- 單字手動改讀音、單字兒化修正。

## 開發計畫&待修正問題

### 計畫中

- 音標方案已涵蓋主要體系（九種），暫不再新增；華語羅馬拼音 (THL) 經評估後放棄實作。
- 粵語拼音（粵拼）支援：粵音標音標準較混亂，不保證效果，目前暫未找到權威標準檔案（如政府標準、學校教材）與可用開源函式庫，歡迎提供參考資料。

## 已知問題

- 讀音錯誤 / 缺音：注音由內建的拼音引擎自動判斷，個別字可能讀錯或讀音不全。我針對常見問題做過補充，但沒法涵蓋全部情況。遇到錯音可以直接點那個字手動改；如果點了發現候選裡也沒有正確讀音，歡迎回饋給我，我補上。
- 閱讀模式：
  - 朗讀讀音由手機 / 電腦 / 瀏覽器內建的語音引擎決定，多音字讀法可能和標註不一致，目前沒找到兼顧低成本與體驗的解法；
  - 句子正好跨在兩頁的分界上時，翻頁的地方朗讀會頓一下再繼續，屬於效能與功能的取捨，近期不打算解決；
  - 麥克風跟讀靠辨識出的字對齊進度，遇到兩三個字的常用短語偶爾會定位錯句；
  - 朗讀高亮按字元位置定位，文章裡如果有 emoji 符號，高亮可能會出現偏移。
