贴好文章，拼音就显示在这里

拼音由引擎自动判断：不同版本词典不同，准确率也不同（完整词典版最高），都做不到 100%。教学前建议勾「易错字」过一遍，有疑问的字点一下就能改读音。

怎么用

  1. 贴文章：粘贴到输入框，或点「导入 TXT」选文件（自动识别 UTF-8 / GBK）。超过 3 万字会自动进入长文模式，最多 200 万字，编辑框变成只读，点「退出长文模式」可回到编辑。
  2. 选音标：「音标方案」有九种——汉语拼音、通用拼音、耶鲁、威妥玛严式 / 简式、注音、注音二式、国语罗马字、西里尔转写。只换写法，读音不变；威妥玛简式和西里尔还能选「数字 / 不标」。
  3. 调排版：字号、字体、音标字体随时换；「拼音位置」可放字上方或右侧（注音模式是「横排 / 直排」）；字距、行距、段距拖动即生效。改乱了点「恢复默认」。
  4. 查读音：勾「易错字」会用底色标出多音字、儿化、的 / 地 / 得、一 / 不、轻声；点预览里任意一个字可换读音，轻声和助词读音都在候选里；点「儿」字可决定儿化还是单独读。
  5. 打印：预览按 A4 自动分页，所见即所印；「打印 / PDF」一次输出全部页。长文模式会先问打印哪几页，也可以分批打印（每批 100 页）再合成一个 PDF，全程在本机完成。
  6. 复制：「复制」有五种格式——粘贴到 Word、网页 ruby 标签、网页注音（HTML+CSS）、字-音标对照、只复制音标。
  7. 给孩子读：点「阅读模式」收起编辑区，方向键翻页；底部工具条可逐句高亮、朗读、麦克风跟读（实验），下次进来接着读。
  8. 界面与读音：右上角切简体 / 繁体 / English；「更多设置」里可换台湾读音、把文章转成繁体（完整词典版和注音版）、列出本机字体、检查拼音引擎更新。

全部处理都在你自己的浏览器里完成，文章不会上传。只有「检查更新」「在线字体」和第一次「合并 PDF」会联网，都不涉及文章内容。麦克风跟读用浏览器自带的语音识别，音频可能由浏览器厂商处理，介意就别开。
