怎么用

  1. 把文章粘贴进左侧输入框，或点「导入 TXT」选择 txt 文件（自动识别 UTF-8 / GBK 编码）；点击预览中的生字可手动改读音，轻声 / 助词读音（子 zi、地 de、着 zhe 等）已收录候选，常见轻声词（豆子、椅子、高兴地等）自动标注；调好后点「保存样式」存为下次打开的默认值（仅保存在本浏览器，清除浏览器数据后恢复默认）；
  2. 音标字体：拼音模式默认用内置 Andika（免费商用），也可选更接近教材的「印氪先生拼音字体」，或勾选「列出本机全部已安装字体」从本机字体里挑（需较新版本的 Chrome / Edge 并允许「字体访问」权限）；注音模式默认用内嵌的 ㄅㄆㄇ 字体 BpmfSubset——手动选过其他字体后不再自动切换；
  3. 「分词方案」选「智能分词」时按内置约 3 万词词典把词组连排、整词标注（如 银行 yín háng）；机器切错时点击生字，可在弹窗里断词 / 合词手动修正；
  4. 预览按 A4 纸宽高自动分页、所见即所印，「翻页 / 连续滚动」随时切换（手机等窄屏自动连续排版）；点「打印 / 导出 PDF」即可输出全部页面；
  5. 点「进入阅读模式」隐藏编辑区，方便把设备直接递给小朋友，←→ 方向键也能翻页；
  6. 阅读模式底部新增跟读工具条：逐句高亮、自动滚动、语音朗读与麦克风跟读，并记住上次读到的位置；点阅读模式中的字可直接跳到该句。语音朗读使用浏览器内置 Web Speech API；麦克风跟读依赖浏览器语音识别服务，可能联网处理音频，介意时请勿开启。
  7. 「复制内容及音标」支持五种格式：富文本（直接粘贴进 Word）、HTML ruby 标签、HTML+CSS 注音（网页源码，横排 / 直排都与预览一致，可配网络字体；直排配「注音芫荽」字体时读音以 IVS 写入文字）、字「音标」逐字对照、只复制音标（含标点）。Word 对注音声调定位的支持有限，富文本中注音为横排、声调符号缀在符号末尾，需要精确排版请用后两种格式粘贴进网页；
  8. 「儿化音」支持逐字注音（花儿 huā er）与标准拼音（花儿 huār）两种方式，自动判断不准时点「儿」字手动指定；勾选「易错点高亮」会用底纹标出多音字、的地得、一 / 不变调、常见轻声字，方便快速核对；拼音引擎已内嵌、离线可用，联网时会自动同步上游更新；
  9. 关于粤语注音：粤拼等标音方案的标准较为混乱，暂未找到权威的教学标准和可用的开源库，本工具暂时只支持汉语拼音与注音符号；欢迎香港的朋友提供权威参考资料或推荐可用方案；

内容安全说明：全部注音转换都在您自己的浏览器里完成，文章内容不会上传到任何服务器，可以放心处理校内稿件。「一 / 不」默认按实际读音标注变调，如需与教材原调标注一致，可切换为「标原调」。「检查更新」仅联网获取拼音引擎的新版本，不会上传文章内容。
